# Jendela Makan

Tracker puasa intermiten 16:8 pribadi: jendela makan, pengecualian dinas, americano, bebas gula/tepung, air putih, protein, tidur, berat badan, dan rekap hasil.

Setiap makan bisa diisi menunya (nasi & karbo, lauk hewani, tahu/tempe, sayur, buah, minuman, pelengkap; bisa beberapa lauk, porsi per ½). Tiap item punya patokan kalori dan protein, jadi total sepiring terlihat. Target kalori harian dihitung dari profil (Mifflin-St Jeor × aktivitas − defisit) dan dibandingkan dengan yang dimakan di Hari ini dan Rekap.

Aplikasi web (PWA) tanpa login. Semua catatan disimpan di HP masing-masing (localStorage), tidak dikirim ke server mana pun.

## Pasang di HP
- **Android (Chrome)**: buka link GitHub Pages, menu ⋮ → *Tambahkan ke layar utama* / *Instal aplikasi*.
- **iPhone (Safari)**: buka link, tombol Bagikan → *Tambahkan ke Layar Utama*.
